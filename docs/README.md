# Platform documentation

This is the platform root. It holds the brand and design standards the rest of the
[`dileepadev`](https://github.com/users/dileepadev/projects/1) platform implements, and the
cross-repository roadmap. The current release work is the v2.1.0 monochrome brand rollout;
the completed v2.0.0 migration remains documented as history.

Start with [`brand/design-system.md`](brand/design-system.md) for the current brand contract,
or [`architecture/platform-overview.md`](architecture/platform-overview.md) for the platform's
data flow.
